# 🤖 Friendly AI

A friendly AI chatbot built using Python, Streamlit and Ollama.

## ✨ Features

- 💬 Ask questions
- 📚 Study assistance
- 💻 Coding help
- 📝 Writing assistance
- 📄 Resume help
- 💡 Project ideas
- 🧠 General knowledge

## 🛠️ Technologies

- Python
- Streamlit
- Ollama
- Llama 3.2

## ▶️ Run Locally

```bash
pip install -r requirements.txt
ollama pull llama3.2
streamlit run app.py
